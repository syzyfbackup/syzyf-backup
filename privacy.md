# Privacy Policy – Syzyf Backup

**Last updated: November 20, 2026**

## 1. Overview

Syzyf Backup is a private application operated by an individual for personal backup purposes. It is not a commercial service and is not offered to third parties.

## 2. Data Access

The application accesses Google Drive through the Google Drive API using OAuth 2.0 authorization.

It accesses only files and folders created or opened by the application, in accordance with the granted `drive.file` permission.

## 3. Data Storage and Security

Backup data is encrypted locally using Restic before being uploaded to Google Drive.

The application does not transmit unencrypted backup contents to Google Drive.

OAuth credentials and encryption passwords are stored securely on the owner's private server.

## 4. Data Sharing

The application does not sell, share, or disclose personal data to third parties.

Google Drive is used solely as encrypted backup storage.

## 5. Data Retention and Deletion

Backup retention is managed automatically by the owner. Older backup data may be permanently deleted according to the configured retention policy.
